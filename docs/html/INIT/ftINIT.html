0463 % At this stage the model will contain some exchange reactions but probably
0464 % not all (and maybe zero). This can be inconvenient, so all exchange
0465 % reactions from the reference model are added, except for those which
0466 % involve metabolites that are not in the model.
0467 
0468 %Start from the original model, and just remove the reactions that are no longer there (and keep exchange rxns). The model we got out
0469 %from the problem is not complete, it does not have GRPs etc.
0470 %The logic below is a bit complicated. We identify the reactions that should be removed from the full model as
0471 %reactions that have been removed in the init model except the ones that were added back. In addition, we make
0472 %sure that no exchange rxns are removed - they can be removed in the init model if they were linearly merged with other
0473 %reactions that were decided to be removed from the model. We want to keep all exchange rxns to make sure the tasks can
0474 %be performed also without manipulating the b vector in the model (which is what is done in the gap-filling).
0475 exchRxns = getExchangeRxns(prepData.refModel);
0476 deletedRxnsInINIT = setdiff(prepData.refModel.rxns,union(union(initModel.rxns, addedRxnsForTasks), exchRxns));
0477 outModel = removeReactions(prepData.refModel, deletedRxnsInINIT, true, true);

0480 % depending on their role (isozyme or complex subunit) in each grRule.

0482 % any default parameters therein.
0483 if ( removeGenes )
0484     [~, geneScores] = scoreModel(outModel,hpaData,transcrData,tissue,celltype);
0485     outModel = removeLowScoreGenes(outModel,geneScores);
0486 end
