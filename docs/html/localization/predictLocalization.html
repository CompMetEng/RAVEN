predictLocalization

PURPOSE

predictLocalization Assign reactions to compartments using localization predictors.

SYNOPSIS

function [outModel, geneLocalization, transportStruct, scores,removedRxns] = predictLocalization(model, GSS,defaultCompartment, varargin)

DESCRIPTION 

 predictLocalization  Assign reactions to compartments using localization predictors.

 Assigns reactions to compartments so that the assignment agrees with the localization
 predictors and the network stays connected.

 Parameters
 ----------
 model : struct
     a model structure. If the model contains several compartments, they
     are merged.
 GSS : struct
     a gene scoring structure as from parseScores.
 defaultCompartment : char
     transport reactions are expressed as diffusion between the
     defaultCompartment and the others. The compartment is usually the cytosol. It must
     be one of GSS.compartments.

 Name-Value Arguments
 --------------------
 transportCost : double
     the cost for including a transport reaction. A scalar applies the same cost to all
     metabolites; a vector must have the same dimension as model.mets. A negative cost
     favours transport of the metabolite (default 0.5).
 maxTime : double
     maximum optimisation time in minutes (default 15).
 plotResults : logical
     true to plot the results during the optimisation (default false).

 Returns
 -------
 outModel : struct
     the resulting model structure.
 geneLocalization : struct
     structure with the genes and their resulting localisation.
 transportStruct : struct
     structure with the inferred transport reactions and the compartments between which
     they transport.
 scores : struct
     structure with the total score history, the score based on gene localisation and
     the score based on the included transport reactions.
 removedRxns : cell
     cell array with the ids of the reactions removed to obtain a connected input model.

 Notes
 -----
 The starting network must be connected when it is in one compartment. Unconnected
 reactions are removed and returned in removedRxns. If many reactions are removed,
 fillGaps can produce a more connected input model. The input model must not include
 exchange, demand or sink reactions; otherwise the function provides no results.

 In the final model, every metabolite is produced in at least one reaction. Internal
 loops can still make the model non-functional. Transport reactions are included only
 as passive diffusion (A <=> B).

 The score of a model is the sum of the scores of all genes in their assigned
 compartment minus the cost of all included transport reactions. A gene is assigned
 to one compartment, which limits the problem size. The problem is solved by simulated
 annealing.

 Examples
 --------
     [outModel, geneLocalization, transportStruct, scores, removedRxns] = ...
         predictLocalization(model, GSS, defaultCompartment, ...
             transportCost, maxTime, plotResults);

0794 function [S, g2c]=moveGene(S,model,g2c,geneToMove,toComp,nRxns,nMets)

0797 g2c(geneToMove,:)=false;
0798 g2c(geneToMove,toComp)=true;

0802

0805

0807 newRxns=I+(toComp-1)*nRxns;

0822 %Finds which metabolites are unconnected, in the sense that they are never
0823 %a product or only a product in a reversible reaction where one reactant is
0824 %only a product in the opposite direction of that reaction. This function
0825 %ignores exchange metabolites. Returns a vector of metabolite indexes.
0826 %metsToCheck is an array of metabolite indexes to check for connectivity.
0827 %If not supplied then all metabolites are checked
0828 function unconnected=findUnconnected(S,nEM,metsToCheck)
0829 if nargin>2
0830     %Do this by deleting everything from the network that is not in
0831     %metsToCheck and that is not exchange metabolites
0832     I=false(size(S,1),1);
0833     I(1:nEM)=true;
0834     I(metsToCheck)=true;
0835     S=S(I,:);
0836 end
0837 
0838 em=false(size(S,1),1);
0839 em(1:nEM)=true;
0840 
0841 %Construct a matrix in which the reversible reactions are inverted
0842 I=sum(S>2,1) | sum(S>2,1);
0843 revS=S;
0844 revS(:,I)=revS(:,I)*-1;
0845 
0846 %First calculate the ones that are ok
0847 %Produced in 2 rxns, is exchange, is not used at all, is produced in
0848 %non-reversible, involved in more than 1 reversible reactions
0849 connected=sum(S>0,2)>1 | em | sum(S~=0,2)==0 | sum(S(:,~I)>0,2)>0 | sum(S(:,I)~=0,2)>1;
0850 
0851 %Then get the ones that are unconnected because they are never produced
0852 unconnected=sum(S>0 | revS>0,2)==0 & connected==false;
0853 
0854 %Then get the ones that are potentially unconnected
0855 maybeUnconnected=~connected & ~unconnected;
0856 %maybeUnconnected=find(maybeUnconnectedS);
0857 
0858 %The metabolites in maybeUnconnected are involved in one reversible
0859 %reaction and not produced in any other reaction. This means that the
0860 %reactions which have at least one met in maybeUnconnected as reactant and
0861 %one as product are unconnected. The metabolites in maybeUnconnected that
0862 %are present in those reactions are then dead ends
0863 deadRxns=any(S(maybeUnconnected,:)>0) & any(S(maybeUnconnected,:)<0);
0864 
0865 %Get the mets involved in any of those reactions
0866 problematic=any(S(:,deadRxns)~=0,2);
0867 
0868 %If any of these are in the maybeUnconnected list then the metabolite is
0869 %unconnected
0870 unconnected(problematic & maybeUnconnected)=true;
0871 
0872 %Map back to metsToCheck
0873 if nargin>2
0874     unconnected=metsToCheck(unconnected(nEM+1:end));
0875 else
0876     unconnected=find(unconnected);
0877 end
0878 end

0880 %Given a set of unconnected metabolites, this function tries to move each
0881 %gene that could connect any of them, calculates the number of newly
0882 %connected metabolites minus the number of newly disconnected metabolites.
0883 %As some metabolites are very connected, only 25 genes are checked. Genes
0884 %that have a low score in their current compartment are more likely to be
0885 %moved
0886 function [geneIndex, moveTo, deltaConnected, deltaScore]=selectGenes(S,nEM,nMets,nER,nRxns,model,unconnected,g2c,GSS)
0887 %If moveTo is 0 then the gene cannot connect any of the metabolites
0888 moveTo=zeros(numel(model.genes),1);
0889 deltaConnected=zeros(numel(model.genes),1);
0890 
0891 %First get where the metabolites are now
0892 nComps=size(g2c,2);
0893 comps=ceil((unconnected-nEM)/((size(S,1)-nEM)/nComps));
0894 
0895 %Find the corresponding metabolite indexes if they all were in the default
0896 %compartment
0897 dcIndexes=unique(unconnected-(comps-1)*nMets);
0898 
0899 %Then find them if they were in any other compartment
0900 allIndexes=dcIndexes;
0901 for i=1:nComps-1
0902     allIndexes=[allIndexes;dcIndexes+nMets*i];
0903 end
0904 
0905 %Also check which reversible reactions that could be used
0906 I=sum(S>2,1) | sum(S>2,1);
0907 revS=S;
0908 revS(:,I)=revS(:,I)*-1;
0909 
0910 %Find all reactions that could make any of the unconnected metabolites in
0911 %some other compartment
0912 newMets=setdiff(allIndexes,unconnected);
0913 [~, potential]=find(S(newMets,:)>0 | revS(newMets,:)>0);
0914 potential(potential<=nER | potential>nER+nRxns*nComps)=[]; %No exchange rxns or transport rxns
0915 
0916 %Map J to the real metabolic reactions in model
0917 rxnComps=ceil((potential-nER)/(nRxns));
0918 
0919 %Find the corresponding reaction indexes if they all were in the default
0920 %compartment
0921 dcRxnIndexes=potential-(rxnComps-1)*nRxns;
0922 
0923 %Get the genes for those reactions
0924 genes=find(sum(model.rxnGeneMat(dcRxnIndexes,:)>0,1));
0925 
0926 %For some cases there can be very many reactions to connect something. This
0927 %is in particular true in the beginning of the optimization if, say, ATP is
0928 %unconnected. Therefore limit the number of genes to be checked to 25.
0929 %Weigh so that genes with bad scores in their current compartment are more
0930 %likely to be moved.
0931 
0932 %Get scores for these genes
0933 [~, J]=find(g2c(genes,:));
0934 
0935 %Add a small weight so that genes in their best compartment could be moved
0936 %as well
0937 geneScores=GSS.scores(sub2ind(size(g2c),genes(:),J));
0938 modGeneScores=1.1-geneScores;
0939 if numel(genes)>25
0940     rGenes=genes(randsample(numel(genes),min(numel(genes),25),true,modGeneScores));
0941     
0942     %The sampling with weights could give duplicates
0943     rGenes=unique(rGenes);
0944     
0945     %Reorder the geneScores to match
0946     [~, I]=ismember(rGenes,genes);
0947     geneScores=geneScores(I);
0948     genes=rGenes;
0949 end
0950 for i=1:numel(genes)
0951     %Since one gene is moved at a time, only metabolites involved in any of
0952     %the reactions for that gene can become unconnected. This helps to
0953     %speed up the algorithm. First get all involved reactions in the
0954     %default compartment
0955     rxns=find(model.rxnGeneMat(:,genes(i)));
0956     
0957     %Then get their mets
0958     mets=find(sum(model.S(:,rxns)~=0,2)>0);
0959     
0960     %Then get their indexes in all compartments
0961     allIndexes=mets;
0962     for j=1:nComps-1
0963         allIndexes=[allIndexes;mets+nMets*j];
0964     end
0965     
0966     %Check which of the unconnected metabolites that these reactions
0967     %correspond to. This could have been done earlier, but it is fast. The
0968     %reversibility check is skipped because it is unlikely to be an issue
0969     %here. Worst case is that the gene is tested once to much
0970     [I, ~]=find(model.S(:,rxns));
0971     moveToComps=unique(comps(ismember(dcIndexes,I)));
0972     
0973     %Try to move the gene to each of the compartments
0974     bestMove=-inf;
0975     bestComp=[];
0976     for j=1:numel(moveToComps)
0977         newS=moveGene(S,model,g2c,genes(i),moveToComps(j),nRxns,nMets);
0978         
0979         %Check how many metabolites that are unconnected after moving the
0980         %gene
0981         dConnected=numel(unconnected)-numel(findUnconnected(newS,nEM,[allIndexes;unconnected]));
0982         if dConnected>bestMove
0983             bestMove=dConnected;
0984             bestComp=moveToComps(j);
0985         end
0986     end
0987     
0988     %Add the difference in connectivity and where the genes should be moved
0989     moveTo(genes(i))=bestComp;
0990     deltaConnected(genes(i))=bestMove;
0991 end
0992 
0993 %Finish up
0994 geneIndex=genes(:);
0995 moveTo=moveTo(geneIndex);
0996 deltaConnected=deltaConnected(geneIndex);
0997 deltaScore=GSS.scores(sub2ind(size(g2c),geneIndex(:),moveTo))-geneScores;
0998 end
