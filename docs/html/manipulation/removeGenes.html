removeGenes

PURPOSE

removeGenes Delete a set of genes from a model.

SYNOPSIS

function reducedModel = removeGenes(model,genesToRemove,varargin)

DESCRIPTION 

 removeGenes  Delete a set of genes from a model.

 Parameters
 ----------
 model : struct
     a model structure.
 genesToRemove : cell or logical or double
     either a cell array of gene IDs, a logical vector with the same number
     of elements as genes in the model, or a vector of indexes to remove.

 Name-Value Arguments
 --------------------
 removeUnusedMets : logical
     remove metabolites that are no longer in use (default false).
 removeBlockedRxns : logical
     remove reactions that get blocked after deleting the genes (default
     false).
 standardizeRules : logical
     format gene rules to be compliant with the standard format (default
     true).

 Returns
 -------
 reducedModel : struct
     an updated model structure. Genes in genesToRemove that are not in the
     model are ignored. When none of them is in the model, no gene, reaction
     or bound changes (with standardizeRules true the gene rules are still
     written in the standard format). Otherwise, besides genesToRemove, every
     gene that no remaining reaction used before the removal is deleted as
     well, also when it was not requested (for example a gene that no
     reaction uses). A gene whose only reaction is kept but blocked
     (removeBlockedRxns false), such as the other subunit of a complex that
     lost one, stays.

 Examples
 --------
     reducedModel = removeGenes(model, genesToRemove, removeUnusedMets, ...
                        removeBlockedRxns, standardizeRules);
