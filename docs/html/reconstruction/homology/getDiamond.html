getDiamond

PURPOSE

getDiamond Bidirectional BLAST with DIAMOND against template organisms.

SYNOPSIS

function [blastStructure,diamondReport]=getDiamond(organismID,fastaFile,modelIDs,refFastaFiles,varargin)

DESCRIPTION 

 getDiamond  Bidirectional BLAST with DIAMOND against template organisms.

 Parameters
 ----------
 organismID : char
     the id of the organism of interest. This should also match with the
     id supplied to getModelFromHomology.
 fastaFile : char
     a FASTA file with the protein sequences for the organism of interest.
 modelIDs : cell
     a cell array of model ids. These must match the "model.id" fields in
     the "models" structure if the output is to be used with
     getModelFromHomology.
 refFastaFiles : cell
     a cell array with the paths to the corresponding FASTA files.

 Name-Value Arguments
 --------------------
 developMode : logical
     true if diamondReport is filled, as used in the unit test for DIAMOND
     (default false).
 hideVerbose : logical
     true if no status messages should be printed (default false).

 Returns
 -------
 blastStructure : struct
     structure array with one element per search direction and template
     organism (2 times the number of modelIDs), containing the bidirectional
     homology measurements (fromId, toId, fromGenes, toGenes, evalue,
     identity, aligLen, bitscore and ppos) for use by getModelFromHomology.
 diamondReport : struct
     structure containing MD5 hashes for FASTA database files and
     unparsed DIAMOND output data. The fields are empty if developMode is
     false.

 Notes
 -----
 This function calls DIAMOND to perform a bidirectional homology search
 between the organism of interest and a set of other organisms using the
 "--more-sensitive" setting from DIAMOND. getBlast() gives the most
 sensitive results; getDiamond() is >15x faster. The blastStructure is in
 the same format as that obtained from getBlast().

 Examples
 --------
     [blastStructure,diamondReport] = getDiamond(organismID,fastaFile,...
        modelIDs,refFastaFiles,developMode,hideVerbose);

 See also
 --------
 getModelFromHomology, getBlast, runSuppOrth
