0004 % Progress-reporting class used by RAVEN functions. The rendering backend is
0005 % selected automatically. The same calls work on an interactive desktop, in a
0006 % command-line session and on a headless server. During unit tests no output
0007 % is produced. The backends are:
0008 %
0009 %   - 'gui'  : MATLAB waitbar (interactive desktop).
0010 %   - 'cli'  : animated command-line bar (interactive terminal).
0011 %   - 'log'  : plain milestone lines, for example "Running BLAST: 30%", printed
0012 %              every 10%. The lines contain no control characters, so they
0013 %              are readable in redirected logs and on headless and -batch
0014 %              servers.
0015 %   - 'none' : no output (during tests, or when disabled).
0016 %
0017 % setRavenProgress sets the backend: setRavenProgress('log') selects plain
0018 % lines, for example on a compute cluster, and setRavenProgress('off')
0019 % disables all progress reporting.
0020 %
0021 % Usage
0022 % -----
0023 % To register each iteration, call count once per pass:
0024 %
