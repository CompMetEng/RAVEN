randomSampling

PURPOSE

randomSampling Sample the flux solution space (entry point for all samplers).

SYNOPSIS

function [solutions, goodRxns, info]=randomSampling(model,varargin)

DESCRIPTION 

 randomSampling  Sample the flux solution space (entry point for all samplers).

 Dispatches to one of three sampling methods via the 'method' argument:
   'achr' (default)  Artificially Centered Hit-and-Run; near-uniform MCMC
                     sampling of the polytope interior (see sampleACHR).
   'chrr'            Coordinate Hit-and-Run with Rounding; near-uniform MCMC
                     with maximum-volume-ellipsoid rounding, which improves
                     mixing on thin or ill-conditioned polytopes such as
                     enzyme-constrained models (see sampleCHRR).
   'randomObjective' the random-objective vertex method of Bordel et al. (2010)
                     PLoS Comput Biol (doi:10.1371/journal.pcbi.1000859): each
                     sample optimises a random objective of nObjectives
                     reactions with random weights, returning a polytope
                     vertex.

 The 'achr' and 'chrr' methods draw from the (near-)uniform distribution
 over the interior; the 'randomObjective' method draws vertices. Arguments
 below marked [randomObjective] apply only to that method; 'thinning' and
 'nBurnin' apply only to the MCMC methods.

 Parameters
 ----------
 model : struct
     a model structure.

 Name-Value Arguments
 --------------------
 nSamples : double
     the number of solutions to return (default 1000).
 method : char
     sampling method: 'achr' (default), 'chrr', or 'randomObjective'.
 thinning : double
     MCMC steps between recorded samples for 'achr' and 'chrr' (default 100).
 nBurnin : double
     burn-in steps discarded before the first sample for 'chrr' (default 1000).
 replaceBoundsWithInf : logical
     [randomObjective]
     replace the largest upper bounds with Inf and the smallest lower
     bounds with -Inf (the latter only if the smallest lower bound is
     negative). This is required to get solutions without loops if the
     model has arbitrarily large bounds, for example 1000 and -1000. A
     model with only biologically relevant bounds can use false
     (default true).
 supressErrors : logical
     if false, randomSampling raises an error after 99 consecutive failed
     attempts to find a non-zero solution that is not involved in loops.
     Failures can result from constraints that are too relaxed (such as
     unlimited glucose uptake) or too strict (such as many narrow
     constraints). If true, the attempts continue without an error
     (default false).
 runParallel : logical
     run the calculations in parallel (default true). Requires the MATLAB
     Parallel Computing Toolbox; without it, the calculations run serially
     regardless of this setting.
 goodRxns : double
     vector of indexes of those reactions that are not involved in loops
     and can be used as random objective functions, as generated by a
     previous run of randomSampling on the same model (default empty).
 minFlux : logical
     determines if a second optimisation is performed for each random
     sample, which minimises the sum of absolute fluxes to prevent loops
     (default false).
 nObjectives : double
     number of reactions included in the random objective function per
     sample iteration (default 2).
 seed : double
     random seed for reproducibility. If empty, the current MATLAB random
     state is used (default empty).

 Returns
 -------
 solutions : double
     matrix with the solutions.
 goodRxns : double
     [randomObjective] vector of indexes of those reactions that are not
     involved in loops or always carry zero flux and can be used as random
     objective functions. Empty ([]) for the 'achr' and 'chrr' methods.
 info : struct
     [chrr] the diagnostics from sampleCHRR, including mveConverged (whether
     the maximum-volume ellipsoid rounding reached tolerance). Empty ([])
     for the 'achr' and 'randomObjective' methods.

 Notes
 -----
 With 'randomObjective', the solutions are generated by optimising (with
 random weights) a random set of nObjectives reactions (default 2). The
 sign of each weight is chosen at random, which selects maximisation or
 minimisation of the reaction; reactions with an upper bound below 0 always
 receive a positive weight. The default 'achr' and the 'chrr' methods use
 no random objectives; they take hit-and-run steps through the interior of
 the solution space.

 If the model is a GECKO v3+ ecModel, then usage_prot reactions are not
 selected as random objectives; the objectives are drawn from the
 metabolic reactions.

 Examples
 --------
     % Near-uniform interior sampling (default, ACHR):
     solutions = randomSampling(model, 1000);
     % Coordinate hit-and-run with rounding:
     solutions = randomSampling(model, 1000, 'method', 'chrr', 'seed', 1);
     % Random-objective vertex method:
     solutions = randomSampling(model, 1000, 'method', 'randomObjective');

 See also
 --------
 sampleACHR, sampleCHRR, sampleMaxVolEllipse
