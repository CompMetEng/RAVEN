sampleACHR

PURPOSE

sampleACHR Artificially Centered Hit-and-Run flux sampling.

SYNOPSIS

function solutions = sampleACHR(model, nSamples, thinning, warmup, seed)

DESCRIPTION 

 sampleACHR  Artificially Centered Hit-and-Run flux sampling.

 Draws nSamples flux vectors approximately uniformly from the flux polytope
 {v : S*v = 0, lb <= v <= ub}, using the ACHR algorithm (Kaufman & Smith 1998).
 No rounding is performed, so on strongly elongated polytopes (for example
 enzyme-constrained models) mixing is slower than with sampleCHRR, which
 rounds the polytope.
 Reactions whose bounds or warmup values coincide never move. The remaining
 reactions are corrected towards S*v = 0 every few steps and before each
 recorded sample, with a sparse Cholesky factor of the row-normalised S*S'
 (no dense null-space basis), so the rounding error in S*v does not grow with
 the number of steps and samples stay inside the bounds. The guarantee
 S*v = 0 holds for a well-conditioned S and warmup points that are feasible
 for the model. When the largest residual of a recorded sample exceeds 1e-9
 times max(1, max(abs(v))) (nearly dependent rows of S, a noisy or infeasible
 warmup), sampleACHR issues the warning sampleACHR:steadyStateNotRestored.

 Parameters
 ----------
 model : struct
     a model structure.
 nSamples : double
     number of flux vectors to return (default 1000).
 thinning : double
     Markov-chain steps between recorded samples (default 100).
 warmup : double
     nPoints-by-nRxns warmup vertices (default: generated by sampleWarmupPoints).
 seed : double
     random seed for reproducibility (default: current RNG state).

 Returns
 -------
 solutions : double
     nRxns-by-nSamples matrix of sampled flux distributions.
